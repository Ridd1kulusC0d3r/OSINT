# OSINT • Aprender, investigar, documentar

Base de estudos e prática em Inteligência de Fontes Abertas, por **Deivison Lourenço**.

Este repositório organiza fundamentos, exercícios e modelos para transformar observações em conclusões rastreáveis. Comece com uma pergunta delimitada e termine com uma resposta que mostre evidências e incertezas.

## Como estudar

1. Leia [o método](docs/metodo.md).
2. Complete o primeiro laboratório sem consultar a resolução.
3. Registre o que observou, o que inferiu e o que permanece desconhecido.
4. Compare com a resolução e explique as diferenças.
5. Proponha uma melhoria ou novo laboratório em uma issue.

## Critério de qualidade

Uma entrada útil informa objetivo, fonte, data, limitações e próximo passo. Quantidade de links não substitui avaliação. Nos exercícios, use dados sintéticos, próprios ou autorizados. Não publique dados pessoais desnecessários.
