# Método: da pergunta à conclusão

[Início](../README.md)

## 1. Delimite

Escreva a decisão que a pesquisa deve apoiar. “Conhecer tudo sobre uma organização” é amplo demais. “Verificar se dois comunicados informam a mesma data para um evento” é verificável.

Defina período, fontes, exclusões e condição de encerramento. Não interprete falta de resultado como inexistência.

## 2. Colete com contexto

Registre URL ou identificador, título, data de publicação, instante de consulta com fuso e trecho relevante. Para arquivos locais, registre também o hash se necessário. Um hash ajuda a detectar mudanças; não prova que o conteúdo é verdadeiro.

## 3. Separe três camadas

| Camada | Exemplo |
|---|---|
| Observação | Dois documentos citam o mesmo fornecedor |
| Inferência | Pode haver uma dependência compartilhada |
| Desconhecido | Não sabemos se os autores têm ligação entre si |

Uma fonte pode copiar outra. Duas páginas não significam duas confirmações independentes.

## 4. Compare explicações

Registre hipótese principal, alternativa, evidências favoráveis e contrárias. Evite porcentagens de confiança sem calibração. Prefira uma avaliação justificada e explicite os limites.

## 5. Entregue e revise

Responda à pergunta inicial. Relacione afirmações aos IDs das evidências. Inclua lacunas, próximos passos e data de revisão.

Use o [plano](../templates/plano.md), o [registro](../templates/evidencias.md) e o [relatório](../templates/relatorio.md).
