## Critério para avançar

Você consegue:

- explicar qual fonte originou cada afirmação;
- diferenciar observação de interpretação;
- verificar se duas notícias são realmente independentes;
- explicitar uma hipótese alternativa plausível;
- apresentar data, fuso e limitações;
- produzir uma conclusão que outro leitor possa revisar.

Se algum item faltar, refaça o exercício correspondente. A qualidade não depende de velocidade ou quantidade de ferramentas usadas.
