# Laboratório 01 • Coincidência não é vínculo

[Início](../../README.md) · Duração sugerida: 20 minutos · Sem instalação

## Cenário sintético

Duas páginas fictícias divulgam eventos. Sua missão é avaliar se os registros permitem afirmar que ambos têm o mesmo organizador. Os domínios .invalid abaixo são fictícios e não devem ser consultados.

| ID | Registro fornecido |
|---|---|
| E001 | alfa.invalid informa “Encontro Aurora, 12 de maio de 2026” |
| E002 | beta.invalid informa “Oficina Boreal, 20 de maio de 2026” |
| E003 | Ambos os documentos contêm o crédito “Template Horizonte” |
| E004 | Alfa identifica a organização como “Coletivo Aurora” |
| E005 | Beta não informa o nome da organização no documento fornecido |

## Missões

1. Copie o [registro de evidências](../../templates/evidencias.md).
2. Separe três observações de duas interpretações possíveis.
3. Responda se o crédito compartilhado basta para concluir organização comum.
4. Proponha uma fonte adicional e explique o que ela resolveria.
5. Entregue um parágrafo de conclusão com IDs de evidência.

## Critérios de conclusão

- Cada afirmação aponta para um registro.
- Crédito de template não é tratado como autoria do evento.
- O dado ausente em E005 não vira prova negativa.
- Pelo menos uma hipótese alternativa é apresentada.

<details>
<summary>Resolução comentada — abra após concluir</summary>

E003 sustenta apenas o uso do mesmo crédito de template. Uma explicação é o uso independente de um modelo público; outra é um prestador compartilhado. E004 identifica apenas a organização declarada por Alfa. E005 é uma lacuna no material recebido.

Conclusão possível: os registros não permitem confirmar organizador comum. Uma página oficial de cada evento que identifique a organização seria uma próxima fonte útil. Mesmo essa declaração precisaria ser avaliada quanto à origem e ao contexto.

</details>
