# Como contribuir

1. Escolha uma entrega pequena: corrigir uma explicação, revisar um recurso ou adicionar um laboratório.
2. Informe problema, público e resultado esperado.
3. Use links relativos para conteúdos internos.
4. Para laboratório, inclua cenário, entradas, passos, saída esperada e resolução.
5. Use exemplos sintéticos ou materiais que você tem autorização para publicar.
6. Diferencie conteúdo testado de conteúdo planejado.
7. Abra um pull request explicando o que foi verificado.

Sugestões de novas fontes devem seguir [o modelo do catálogo](recursos/README.md). Não envie credenciais ou dados pessoais de terceiros.
