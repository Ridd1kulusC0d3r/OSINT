# Guias por plataforma · Como usar cada fonte com método

[← Início](../../README.md) · [Mapa de estudos](../indice.md) · [Qualidade e ética](../qualidade-e-etica.md)

Cada plataforma é uma fonte com regras próprias: o que é público, o que ela deixa buscar, como o conteúdo muda e o que a lei e os termos de uso permitem. Estes guias tratam a plataforma como **fonte de verificação**, não como atalho para expor pessoas.

| Grupo | Guia | Use para |
|---|---|---|
| Redes sociais | [Redes sociais](redes-sociais.md) | Verificar publicações, contas institucionais e a origem de um conteúdo viral |
| Buscadores e arquivos | [Buscadores e arquivos da web](buscadores-e-arquivos.md) | Encontrar a primeira publicação, versões antigas e documentos públicos |
| Mapas e imagens | [Mapas e imagens](mapas-e-imagens.md) | Confirmar local e data de uma imagem ou de um evento |
| Registros públicos BR | [Registros públicos no Brasil](registros-publicos-br.md) | Consultar dados oficiais de empresas, órgãos, contratos e processos |

## Estrutura de cada guia

Todo guia segue a mesma ordem, para que a consulta seja rápida:

1. **Para que serve** numa investigação ou verificação.
2. **O que é público** e o que não é.
3. **Recursos nativos** de busca e filtro que a própria plataforma oferece.
4. **Como preservar** o que foi encontrado.
5. **Limites** legais, éticos e dos termos de uso.

## Regras comuns a todas as plataformas

- Consulte com uma conta e um navegador de trabalho, separados dos pessoais.
- Observe; não interaja com quem é objeto da verificação.
- Registre URL, data e hora de consulta com fuso, e preserve antes de analisar.
- Conteúdo público não é conteúdo livre: dados pessoais continuam protegidos pela LGPD.
- Ausência de resultado não prova inexistência.
- Recursos e regras das plataformas mudam com frequência. Cada guia traz a data da última revisão.
